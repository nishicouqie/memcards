# 记忆卡片 · 艾宾浩斯复习

一个**单文件、离线可用**的记忆卡片（Flashcard）Web 应用。打开网页就能用，无需安装、无需注册、无需联网——数据全部保存在你自己的浏览器里。

基于艾宾浩斯遗忘曲线安排复习间隔：**1 → 2 → 4 → 7 → 15 天**，走完五级即「毕业」，不再打扰。

## 在线使用

**→ [https://nishicouqie.github.io/memcards/v3.html](https://nishicouqie.github.io/memcards/v3.html)**

推荐收藏此链接。也可以把 HTML 文件下载到本地，双击直接打开使用（完全离线）。

## 功能总览

四个页签：**复习 · 查看 · 添加 · 数据**

### 📖 复习
- 按**文件夹**复习（如生物、化学），或全部一起复习
- 三种出卡顺序：**按添加顺序 / 随机 / 按进度**（优先先学过的、新加入的）
- 点击卡片翻面，正面问题、反面答案与解析
- 翻面后三档自评，一键安排下次复习时间：

| 按钮 | 含义 | 效果 |
|---|---|---|
| 遗忘 | 完全想不起来 | 降一级，**明天再见** |
| 模糊 | 想起来了但不稳 | 级别不变，按当前间隔 |
| 清楚 | 轻松回忆 | 升一级，进入下一间隔 |

- 支持键盘：`空格` 翻面，`1 / 2 / 3` 评分
- 已毕业的卡片自动退出复习队列

### 👀 查看
所有卡片的「正面墙」，适合快速过一遍、考前串记：

- **按文件夹分组**展示，组间分割线，一行 3 张（窄屏自适应）
- 卡片正面直接渲染 **Markdown + LaTeX 数学公式 + mhchem 化学式**
- 顶部**搜索框**，正面/反面全文匹配，实时过滤
- 点卡片放大到全屏，再点翻面看答案（只读模式）
- 右上角**编辑模式**开关：
  - 点卡片 → 全屏编辑（改正反面、换文件夹、重置进度、删除）
  - **按住卡片拖到其他文件夹的组头**上松手，直接移动归属

### ➕ 添加
- 单张添加，正面/反面**实时预览**渲染效果
- **文本一键导入**——让 AI 帮你制卡后直接粘贴（见下文）：

  ```
  卡片之间用单独一行 === 分隔
  正面与反面用单独一行 --- 分隔
  单行写法：正面 | 反面
  ```

### 📊 数据
- 六项指标：卡片总数、今日待复习、学习中、已毕业、累计复习次数、今日已复习
- **最近 14 天复习量柱状图**（今日红色高亮）
- 各文件夹完成度进度条
- **导出 / 导入 JSON 备份**——换设备、换浏览器、手机↔电脑迁移全靠它

## Markdown · LaTeX · 化学式

反面和正面均完整支持（KaTeX 引擎，离线渲染）：

| 写法 | 效果 |
|---|---|
| `**重点**`、`*斜体*` | 加粗、斜体 |
| `` `代码` ``、```代码块``` | 行内代码、代码块 |
| `- 列表`、`1. 有序` | 列表 |
| `> 引用` | 易错点标注 |
| `$x^2 + \frac{a}{b}$` | 行内数学公式 |
| `$$\int_0^1 x\,dx$$` | 独立公式块 |
| `\ce{H2SO4}` | H₂SO₄（自动下标） |
| `\ce{Zn + 2H+ -> Zn^2+ + H2 ^}` | 配平离子方程式 + 气体符号 |
| `\ce{N2 + 3H2 <=> 2NH3}` | 可逆反应箭头 |

## 搭配 AI 制卡（推荐工作流）

配套提供一份[制卡助手 System Prompt](制卡助手-system-prompt.md)：

1. 把它设为任意 AI 对话的 system prompt
2. 你只管丢问题（或问题 + 答案）
3. AI 直接输出符合导入格式的纯文本：第一行**加粗简洁答案**，下面 2~4 句讲清**本质缘由**，易错点用引用标出
4. 复制 → 粘贴到「添加 → 文本一键导入」→ 一秒生成整套卡片

## 数据与隐私

- 所有数据保存在**浏览器 localStorage**，不上传任何服务器
- 换设备 = 导出 JSON 再导入，两步完成
- 定期导出备份是好习惯（清浏览器缓存会清掉数据）

## 技术说明

- 单 HTML 文件（约 1.1 MB），零构建、零依赖安装
- 内嵌依赖：[marked](https://github.com/markedjs/marked)（Markdown）、[KaTeX](https://github.com/KaTeX/KaTeX) + [mhchem](https://github.com/mhchem/mhchemExtension)（公式与化学式），全部 base64 内联，字体随文件携带
- 复习调度：五级间隔 `1/2/4/7/15` 天，遗忘降级 + 1 天后重学，`模糊` 保持本级间隔
- 兼容现代浏览器（Chrome / Edge / Firefox / Safari），手机竖屏可用
