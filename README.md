# 记忆卡片 · 艾宾浩斯复习

一个**单文件、离线可用**的记忆卡片（Flashcard）Web 应用。打开网页就能用，无需安装、无需注册、无需联网——数据全部保存在你自己的浏览器里。

基于艾宾浩斯遗忘曲线安排复习间隔：**1 → 2 → 4 → 7 → 15 天**，走完五级即「毕业」，不再打扰。

## 在线使用

**→ [https://nishicouqie.github.io/memcards/v6.html](https://nishicouqie.github.io/memcards/v6.html)**

推荐收藏此链接。也可以把 HTML 文件下载到本地，双击直接打开使用（完全离线）。

## 功能总览

七个页签：**复习 · 查看 · 添加 · 数据 · 错题 · 导出 · 设置**

### 📖 复习
- 按**文件夹**复习（如生物、化学），或全部一起复习
- 三种出卡顺序：**按添加顺序 / 随机 / 按进度**（优先先学过的、新加入的）
- 点击卡片或按 `空格` 翻面，正面问题、反面答案与解析
- 翻面后三档自评，一键安排下次复习时间：

| 按钮 | 默认键 | 含义 | 效果 |
|---|---|---|---|
| 遗忘 | `Z` | 完全想不起来 | 降一级，**明天再见** |
| 模糊 | `X` | 想起来了但不稳 | 级别不变，按当前间隔 |
| 记得 | `C` | 轻松回忆 | 升一级，进入下一间隔 |

- 全键盘流：`空格` 翻面 → `Z / X / C` 评分 → 自动下一张；`S` 跳过（翻面把当前卡塞回队尾）
- 键位可在**设置**页改成任何顺手的键
- 已毕业的卡片自动退出复习队列

### 👀 查看
所有卡片的「正面墙」，适合快速过一遍、考前串记：

- **按文件夹分组**展示，组间分割线，一行 3 张（窄屏自适应）
- 卡片正面直接渲染 **Markdown + LaTeX 数学公式 + mhchem 化学式**
- 顶部**搜索框**，正面/反面全文匹配，实时过滤
- 点卡片放大到全屏，再点翻面看答案（只读模式）
- 右上角**编辑模式**开关：
  - 点卡片 → 全屏编辑（改正反面、换文件夹、重置进度、删除）
  - **按住卡片拖到其他文件夹的组头**上松手，直接移动归属

### ➕ 添加
- **文本一键导入放在最上面**——让 AI 帮你制卡后直接粘贴（见下文），首行 `@文件夹名` 自动建文件夹：

  ```
  卡片之间用单独一行 === 分隔
  正面与反面用单独一行 --- 分隔
  单行写法：正面 | 反面
  ```

- 手动新建在下面：单张添加，正面/反面**实时预览**渲染效果

### 📊 数据
- 六项指标：卡片总数、今日待复习、学习中、已毕业、累计复习次数、今日已复习
- **近 20 周复习热力图**（GitHub 贡献墙式、蓝色 token 风）：周一到周日七行、月份刻度、未来日期虚线格、今日描边；可开关**格内数字**显示当天背了几张；附区间合计 / 连续天数 / 峰值读数
- 各文件夹完成度进度条
- **导出 / 导入 JSON 备份**——换设备、换浏览器、手机↔电脑迁移全靠它

### ❌ 错题
- **今日 / 累计**六格：遗忘、模糊、记得各计数
- **每日评分记录**：按天分组，红（遗忘）/ 灰（模糊）/ 蓝（记得）词 chip 平铺，记得过多时折叠为「展开其余 N 张」

### 🖨 导出
专门的导出工作台（「导出」页签，或复习页的「导出卡片」按钮进入），回家没空背也能把卡片带走纸面复习：

- **左栏 · 选卡**
  - **错题批量**：近 14 个有错记的日期 chip，点一下 = 全选当天「遗忘 + 模糊」的卡，再点取消；chip 上直接标红/灰计数
  - **卡片挑选**：搜索框（按 `/` 快速聚焦）+ 文件夹 / 状态筛选；**全选当前 / 反选当前 / 全部错题 / 清空**；列表逐行勾选，行内带文件夹、进度、错次标签
- **右栏 · 格式与预览**
  - 四种出口：**Markdown 下载 / Word (.docx) 下载 / PDF（打印保存）/ 复制 MD**
  - 字段开关：编号、文件夹、状态标注、错次、下次复习日期——勾掉的字段在所有格式里同步消失
  - 排序：选择顺序 / 文件夹 / 进度 / 错次优先；版式：**A4 双栏（高密度）/ 单栏**
  - 实时摘要 + **双栏 live 预览**，公式化学式照常渲染，所见即所得
- **同源排版**：MD、Word、PDF 与预览共用同一排版源——压缩信息密度（一张 A4 可容纳数十张卡），但每张卡正面、反面、元信息一条不丢
  - PDF：新窗口打开独立打印版并自动弹出打印对话框，选「另存为 PDF」即可；新窗口被拦截时自动回退为本页打印
  - Word：真 `.docx`（A4 双栏、9pt 紧凑字号），公式以 TeX 原文等宽保留
- 勾选与格式偏好**单独记忆**（`memcards.v1.export`），下次进入原样恢复；`Esc` 返回进入前的页签

### ⚙️ 设置
- **键盘键位**：翻面 / 遗忘 / 模糊 / 记得 / 跳过五项均可点击键帽后按新键重映射，冲突键会被拒绝并提示；一键恢复默认
- **热力图数字**、**粒子与入场动效**开关（动效关闭后更安静省电）
- 存储占用读数（KB / 卡片数 / 事件数）

## Markdown · LaTeX · 化学式

反面和正面均完整支持（KaTeX 引擎，离线渲染）：

| 写法 | 效果 |
|---|---|
| `**重点**`、`*斜体*` | 加粗、斜体 |
| `` `代码` ``、```代码块``` | 行内代码、代码块 |
| `- 列表`、`1. 有序` | 列表 |
| `> 引用` | 易错点标注 |
| `$x^2 + \frac{a}{b}$` | 行内数学公式 |
| `$$\int_0^1 x\,dx$$` | 独立公式块 |
| `\ce{H2SO4}` | H₂SO₄（自动下标） |
| `\ce{Zn + 2H+ -> Zn^2+ + H2 ^}` | 配平离子方程式 + 气体符号 |
| `\ce{N2 + 3H2 <=> 2NH3}` | 可逆反应箭头 |

## 搭配 AI 制卡（推荐工作流）

配套提供一份[制卡助手 System Prompt](制卡助手-system-prompt.md)：

1. 把它设为任意 AI 对话的 system prompt
2. 你只管丢问题（或问题 + 答案）
3. AI 直接输出符合导入格式的纯文本：第一行**加粗简洁答案**，下面 2~4 句讲清**本质缘由**，易错点用引用标出
4. 复制 → 粘贴到「添加 → 文本一键导入」→ 一秒生成整套卡片

## 数据与隐私

- 所有数据保存在**浏览器 localStorage**，不上传任何服务器
- 换设备 = 导出 JSON 再导入，两步完成
- 定期导出备份是好习惯（清浏览器缓存会清掉数据）

## 技术说明

- 单 HTML 文件（约 1.2 MB），零构建、零依赖安装
- 内嵌依赖：[marked](https://github.com/markedjs/marked)（Markdown）、[KaTeX](https://github.com/KaTeX/KaTeX) + [mhchem](https://github.com/mhchem/mhchemExtension)（公式与化学式），全部 base64 内联，字体随文件携带
- 复习调度：五级间隔 `1/2/4/7/15` 天，遗忘降级 + 1 天后重学，`模糊` 保持本级间隔
- 兼容现代浏览器（Chrome / Edge / Firefox / Safari），手机竖屏可用
